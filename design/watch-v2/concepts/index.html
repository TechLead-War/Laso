Laso Watch redesign — ten concepts

Ten working watchOS prototypes, one per concept. Each one is a different answer to "why would someone raise their wrist?", not a different skin. They are meant to be in tension with each other, so several are mutually exclusive by design. Every prototype is a single self contained HTML file with no network calls, and every number on every screen is computed by the prototype from the shared fictional user in PROTOTYPE-SPEC.md (Alex, 34, Tuesday 14:32).

  • Design target 46mm — 208 × 248 pt
  • Floor 40mm — 162 × 197 pt
  • Dark only, no light mode
  • 10 concepts

Using the dev toolbar

Every prototype ships a Dev panel (a button in the corner, a gear in Live Pulse, a side rail in Health Radar). It is scaffolding for review and is not part of the design being judged. It drives the same four things in all ten:

  • Canvas — switch between 46mm and 40mm. If a layout breaks at 40mm it is not a shipping layout.
  • State — loaded, loading, cold start, empty, error and stale. Every state is drawn, none are placeholders.
  • Always-On — the dimmed isLuminanceReduced render, plus redacted mode where the concept has private data.
  • Key variable — the one value the concept turns on, usually the score band. Moving it re-derives every screen, complication and notification.

Most panels also have a Gesture section to fire watchOS Double Tap. In all ten prototypes the mouse wheel or the up and down arrow keys turn the Digital Crown. Concept specific controls are labelled in each panel.

02

One Word RECOMMENDED · REVISED

The watch should answer, not report — so the entry screen carries one word and no number at all, and the number is one crown turn away for anyone who wants to audit the answer. Revised after review: a word only reaches the headline if the user could not already know it, so STAND, DRINK, WALK and COAST were deleted. Most days it now reads as a state measured against your own baseline (RECOVERING, WARM, STEADY); only REST, TRAIN, BREATHE and SLEEP are orders.

First question
What is my body doing that I could not have known?
Primary surface
App screen
