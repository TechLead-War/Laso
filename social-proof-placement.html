Social proof in onboarding — where it actually fits

Onboarding only. Every image is a real screenshot of the live Laso onboarding (captured just now, iPhone 17 Pro Max). Ranked by impact. The amber marker is the exact gap the line drops into; the styled line under each phone shows how it reads in-app.

One rule that does not bend: the percentage must be your own real number — computed from Laso users' HRV data, then served through the Remote Config copy system. A made-up "38% / 9%" is an FTC and App Store reject risk and breaks trust the second someone checks. If you do not have the number yet, run the cohort analysis first. How to read this

Put the HRV outcome line on the HRV reveal (Screen 13) — that is the one to ship first; it is the most relevant and most felt. Add the plan-outcome line on the First-week plan (Screen 14) as the second beat that drives the paywall. The Bridge and Promise are optional reinforcements. All four need a real number through Remote Config — nothing here ships with an invented stat.
Not recommended: the data-entry screens (goal, symptoms, activity, wearable) break focus, and the welcome / sign-in screens carry no earned context. Reveal screens (heart 54 BPM, sleep 7h 36m) can each carry their own metric-specific stat later using the same pattern.
